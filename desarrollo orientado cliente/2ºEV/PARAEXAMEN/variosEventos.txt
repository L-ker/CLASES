TEMA 7:
Tema 7: Utilización de mecanismos de comunicación asíncrona
La comunicación asíncrona permite que una aplicación ejecute tareas en segundo plano sin bloquear la interfaz del usuario. En JavaScript, esto se logra con tecnologías como IndexedDB y AJAX.

7.1. Acceso a datos con IndexedDB
IndexedDB es una base de datos del navegador que permite almacenar grandes cantidades de datos estructurados.

7.1.1 Crear y abrir la base de datos
Se utiliza indexedDB.open(nombre, versión) para abrir o crear una base de datos.

7.1.2 Control de versiones
Cada base de datos tiene una versión. Si se intenta abrir con una versión superior, se dispara el evento onupgradeneeded.

7.1.3 Crear almacén de objetos
Los datos se almacenan en "almacenes de objetos" (objectStore). Se crean usando db.createObjectStore(nombre, opciones).

7.1.4 Insertar objetos en el almacén de datos
Se usa una transacción (transaction) y el método add() o put() para insertar datos.

7.1.5 Obtener objetos del almacén
Para recuperar datos, se usa get(clave) dentro de una transacción de solo lectura.

7.1.6 Eliminar objetos del almacén
Los elementos pueden eliminarse con delete(clave) dentro de una transacción.

7.2. Comunicación Asíncrona con AJAX
AJAX (Asynchronous JavaScript and XML) permite la comunicación con servidores sin recargar la página.

7.2.1 Introducción a Ajax
Es una técnica para cargar datos de forma dinámica usando JavaScript.

7.2.2 Requisitos para la comunicación asíncrona
Se necesita un navegador compatible, un servidor web y una API como XMLHttpRequest o fetch().

7.2.3 API y Métodos del objeto XMLHttpRequest
Los métodos principales son:

open(método, URL, async): Inicializa la solicitud.
send(): Envía la solicitud al servidor.
7.2.4 Propiedades del objeto XMLHttpRequest
Algunas importantes son:

readyState: Indica el estado de la solicitud.
status: Código de respuesta HTTP.
responseText: Contiene la respuesta del servidor.
7.2.5 XMLHttpRequest
Ejemplo de uso:

Editar

xhr.open("GET", "datos.json", true);
xhr.onload = () => console.log(xhr.responseText);
xhr.send();

JSON (JavaScript Object Notation) es un formato ligero para intercambiar datos con AJAX.

7.2.7 Ejercicios con JSON
Normalmente incluyen solicitudes a APIs y procesamiento de datos en formato JSON.

Ejemplo Provincias:
Para recoger los datos de estos documentos XML generados por PHP en JavaScript, puedes hacer una petición AJAX con fetch(), procesar la respuesta como XML y extraer la información.

1️⃣ Obtener las provincias
Puedes hacer una petición al primer PHP (provincias.php en este ejemplo) para obtener la lista de provincias:

javascript
Copiar
Editar
fetch("provincias.php")
  .then(response => response.text()) // Obtener el contenido como texto
  .then(str => new window.DOMParser().parseFromString(str, "application/xml")) // Convertir a XML
  .then(data => {
    const provincias = data.getElementsByTagName("provincia");
    let selectProvincias = document.getElementById("provincias");

    for (let provincia of provincias) {
      let codigo = provincia.getElementsByTagName("codigo")[0].textContent;
      let nombre = provincia.getElementsByTagName("nombre")[0].textContent;
      
      let option = document.createElement("option");
      option.value = codigo;
      option.textContent = nombre;
      selectProvincias.appendChild(option);
    }
  })
  .catch(error => console.error("Error cargando provincias:", error));
2️⃣ Obtener los municipios de una provincia seleccionada
Cuando el usuario seleccione una provincia, se enviará su código al segundo PHP (municipios.php en este ejemplo) para obtener sus municipios.

javascript
Copiar
Editar
document.getElementById("provincias").addEventListener("change", function() {
  let codigoProvincia = this.value;
  
  fetch("municipios.php", {
    method: "POST",
    headers: { "Content-Type": "application/x-www-form-urlencoded" },
    body: "provincia=" + encodeURIComponent(codigoProvincia)
  })
  .then(response => response.text())
  .then(str => new window.DOMParser().parseFromString(str, "application/xml"))
  .then(data => {
    const municipios = data.getElementsByTagName("municipio");
    let selectMunicipios = document.getElementById("municipios");
    selectMunicipios.innerHTML = ""; // Limpiar antes de añadir nuevos

    for (let municipio of municipios) {
      let codigo = municipio.getElementsByTagName("codigo")[0].textContent;
      let nombre = municipio.getElementsByTagName("nombre")[0].textContent;
      
      let option = document.createElement("option");
      option.value = codigo;
      option.textContent = nombre;
      selectMunicipios.appendChild(option);
    }
  })
  .catch(error => console.error("Error cargando municipios:", error));
});
